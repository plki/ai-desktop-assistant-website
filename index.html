❓ FAQ

Frequently Asked Questions

Does it require an internet connection?
In local mode, it runs fully offline using Ollama. Data never leaves your machine. Internet is only needed for cloud API mode.
Which operating systems are supported?
Windows, macOS, and Linux. Python 3.9+ required. Windows users get a one-click install script (install.bat).
Which AI models are supported?
Local: any Ollama-supported model (Llama, Qwen, Mistral, etc.). Cloud: any OpenAI-compatible API (DeepSeek, Qwen, Moonshot, OpenAI, etc.). Custom Base URL supported.
How do I update to the latest version?
Navigate to the project directory, run git pull to pull the latest, then pip install -r requirements.txt to update dependencies.
Is my API Key safe?
In local mode, the API Key is stored in config/config.json. In cloud web mode, the API Key stays in the visitor's browser localStorage only — it never touches any server.
Can I contribute code?
Absolutely! Licensed under MIT. Submit Issues for bug reports or Pull Requests to contribute. We welcome community participation.
